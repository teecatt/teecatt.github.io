# MWS — Multi-Window Shell（多窗口同步壳）v2.0 · 像素画布模式

通用于任意网站的组件式外壳：**不识别页面任何内容**，而是把整页当成一张不透明位图放在虚拟画布上，各窗口按像素裁剪显示——页面里的按键区、工具栏、琴键全部随画布自然切开。

## 接入（一行，必须放在 `<head>` 内、`<title>` 之后）

```html
<script src="/shell/shell.js"></script>
```

脚本自动分流为两种模式，页面无感知：

| 模式 | 位置 | 行为 |
|---|---|---|
| **host** | 顶层窗口 | `document.open` 接管文档（原 body 脚本不执行），本窗口只放一个 **尺寸=整块画布** 的 `<iframe src=原页面&mws=inner>`，裁剪矩形 `translate(-ox,-oy)`；覆盖层画扫描线/大字钟/水印/面板 |
| **inner** | iframe 内 | 页面正常渲染，完全不知道自己被裁剪；只做窗口互认（静音选主）与业务状态中继 |

几何协议（**物理坐标驱动，任意网格摆放自适应**）：各窗口广播内容区物理原点（`screenX/screenY` + 边框/标签栏修正，F11 全屏自动归零）→ 按 Y 聚类成行、行主序编号（与打开顺序无关）→ **画布 = 全部内容区包围盒**（支持单排/2×2/任意摆放，含行列间隙），每窗裁剪 = 自己的物理矩形 `translate(-ox,-oy)`；resize/拖动/增窗即时广播，画布实时重排。

## 可选适配器（仅业务联动，与布局无关）

```js
window.ShellAdapter = {
  getState(),            // 业务状态快照（JSON 可克隆）
  applyState(data),      // 应用他窗状态（壳保证回声抑制）
  onAssign?(a),          // {index,count,slice:null} — slice 恒为 null（无语义分片）
  applyOffset?(ms),      // 显示偏移（宿主 postMessage 转交自己的 iframe）
};
```

无适配器 = 纯浏览可用；`window.__MWS.notify()` 手动广播状态变化。

## 扫描线（画布坐标，宿主覆盖层绘制）

- 横竖两线同相位，**交点沿画布对角线匀速移动**：去程 `f:0→1`（左上角→右下角），回程 `f:1→0`（原路扫回左上角）
- 一个周期 = 去程 + 回程；**收齐所有可见 host 的 `swdone` 才生成下一轮**（4s 超时兜底）；窗口集合/尺寸变化立即重开
- 协调者 `startCycle` 250ms 节流 + 新窗口 hello **立即回应**（防视图不对称期 cycle 对轰）
- 标定：手机拍两窗读**大字钟**毫秒差 = 显示延迟差 → 「显示偏移」→ `applyOffset`

## 信道与消息

| 信道 | 成员 | 消息 |
|---|---|---|
| `mws.v1` | host | `hello`(w/h) / `state`(sv:序号+扫描轮) / `swdone` / `ping-pong` |
| `mws.page` | inner | `hello`(静音选主) / `page`(psv 状态中继, 仅#1心跳) / `ping-pong` |

## 面板

空闲 3s 自动隐藏（移鼠标唤出）、可拖拽（位置持久化）；含 序号下拉（占用对调）、扫描线开关、显示偏移、RTT、开窗、全屏、帮助。

## 已知边界

- 按钮横跨接缝会被切开（像素分割的固有性质，点击由浏览器正确路由）
- 内存天花板：`Wv×Hv×dpr²×每窗画布数×窗口数`，高 DPR 大墙建议降系统缩放（帮助页有估算告警）
- 后台窗口冻结（有黄条提示拆独立窗）；`app.js` 走 CDN 回退时适配器控制台告警
